<h2>🛠️ How It Works</h2>
<ol>
  <li>Select base and target currencies from dropdowns</li>
  <li>Enter the amount to convert</li>
  <li>Click convert → Fetches live data from exchange rate API</li>
  <li>Displays converted amount instantly with symbol</li>
</ol>
